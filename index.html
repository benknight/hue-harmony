Harmony for Philips Hue Demo

Color harmony

    Lights will appear here once the bridge is connected.

    Drag a light by its handle to move it into a different color slot.

    Settings

    Harmony sets your Philips Hue lights using the color relationships on an artist’s color wheel. Inspired by Adobe Color. Made by Benjamin Knight; source on GitHub.

    Bridge

    Turn this off to set the IP address yourself, for example if you have more than one bridge.

    Lights

    Only checked lights are controlled by Harmony.
